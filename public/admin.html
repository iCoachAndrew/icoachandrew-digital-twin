• Begitu Anda menetapkan file atau folder ke Ring 0 / Ring 1 / Ring 2 / Ring 3 (baik klik satuan +R0..+R3, pilih banyak lewat kotak centang Baca & Assign Massal, maupun klik Sinkronkan dari Google Drive), mesin otomatis membaca seluruh isi file, mengekstrak teksnya (termasuk PDF Non-OCR & PDF Scan OCR), mengonversinya menjadi file Markdown (.md) yang sangat ringan di data/md_knowledge/ring0..3/, dan langsung memasukkannya ke Memori Kecerdasan Digital Twin!
• Status "Unassigned (Belum Diimpor)" artinya file di Google Drive tersebut belum dipetakan ke Ring 0–3 sehingga belum dimasukkan ke memori AI. Jika ada file di folder publik yang memang bukan materi Digital Twin, Anda bisa menandainya sebagai "Irrelevant / Abaikan".

1. Pilih & Batalkan Folder (Toggle 2x Klik)
Penjelajah Drive & Unassign Mudah
  1. Klik tombol "Jelajahi Folder Drive" di atas untuk melihat isi My Drive Anda.
  2. Klik "Jadikan Induk" untuk menetapkan folder utama. Jika salah pencet, klik sekali lagi (klik ke-2) pada tombol "✓ Folder Induk" untuk membatalkan (unassign)!
  3. Begitu juga tombol R0 / R1 / R2 / R3: klik sekali untuk memilih Ring, atau klik ke-2 kali pada Ring yang sedang aktif untuk mengembalikannya menjadi Unassigned.
  4. Untuk file/folder yang tidak relevan di folder publik, klik tombol "Irrelevant" agar diabaikan oleh AI.
2. Fuzzy Search & Assign Massal (.md)
Cari Cepat & Baca Sekaligus
  1. Gunakan kotak Fuzzy Search di dalam Penjelajah Drive untuk mencari nama file/folder di folder saat ini (tahan salah ketik) atau klik "🌐 Cari di Seluruh Drive".
  2. Centang beberapa file/folder sekaligus (atau klik "Pilih Semua"), lalu klik tombol "Baca & Assign Massal ke R0 / R1 / R2 / R3 (.md)".
  3. Semua item terpilih langsung dibaca, dikonversi ke dokumen .md ringan, dan masuk ke memori Digital Twin dalam sekali jalan!
3. Format Dokumen & Pembacaan PDF OCR
PDF Digital, PDF Scan OCR & Konversi .md
  • Format Didukung: PDF (.pdf Non-OCR & OCR), Google Docs, Google Slides, Google Sheets, Word (.docx), Markdown (.md), dan Teks (.txt).
  • PDF Non-OCR & OCR Otomatis: File PDF teks biasa diekstrak langsung secara instan; sedangkan PDF hasil scan gambar otomatis dibaca menggunakan Claude Document Vision OCR.
  • Arsip .md Ringan: Setiap karya yang di-assign memiliki tombol "📄 Lihat .MD" di kartu karya untuk melihat/mengunduh file Markdown ringannya.

Untuk proyek Executive Mentorship Digital Twin seperti iCoachAndrew, kualitas jawaban sangat bergantung pada kemurnian konteks (Context Hygiene) dan pagar epistimologis (Epistemic Boundary). Berikut rekomendasi pengaturan terbaik yang sudah kami siapkan di sistem ini:
