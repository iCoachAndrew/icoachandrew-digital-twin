menu_book 📘 Panduan Mudah (Step-by-Step for Dummies): Cara Menghubungkan Google Drive ke iCoachAndrew (Klik untuk Buka/Tutup) ▼
💡 Konsep Singkat (Mengapa Sangat Mudah?): Anda tidak perlu mengunggah buku/naskah satu per satu ke website. Cukup simpan dokumen Google Docs, Word (.docx), atau Teks (.txt/.md) di dalam folder Google Drive Anda. Sistem iCoachAndrew menggunakan "Akun Robot Pembaca" (Service Account) untuk membaca isi folder tersebut secara aman dan memasukkannya ke Ring 0, Ring 1, Ring 2, atau Ring 3.
Langkah 1 (Di Google Cloud)
Unduh File Kunci .json
  1. Buka console.cloud.google.com dan buat Project baru (mis. iCoachAndrew).
  2. Ketik "Google Drive API" di kotak pencarian atas → klik Enable (Aktifkan).
  3. Buka menu IAM & Admin → Service Accounts → klik + Create Service Account (beri nama bebas, mis. drive-reader) → klik Done.
  4. Klik email Service Account yang baru dibuat → tab Keys → Add Key → Create new key → pilih JSON → file .json akan terunduh ke komputer Anda.
Langkah 2 (Di Halaman Ini)
Upload 1-Klik File .json
  1. Klik tombol "Pengaturan Drive API" di atas.
  2. Klik kotak "Upload File .JSON Service Account (1-Klik)" dan pilih file .json yang baru Anda unduh (tidak perlu buka Notepad!).
  3. Sistem otomatis menyimpan kunci secara terenkripsi dan menampilkan Alamat Email Robot (contoh: drive-reader@...iam.gserviceaccount.com).
  4. Klik tombol "Salin Email Robot".
Langkah 3 (Di Google Drive Anda)
Share Folder & Sinkronkan!
  1. Buka folder karya Andrew Tani di Google Drive Anda.
  2. Klik kanan folder tersebut → Bagikan (Share) → tempel (Paste) Email Robot tadi sebagai Pelihat (Viewer) → klik Bagikan.
  3. Salin link URL folder Google Drive Anda dari browser, tempelkan ke kolom Folder Induk Utama di bawah, lalu klik "Deteksi Sub-Folder Otomatis" atau "Sinkronkan dari Google Drive"!
Tips Otomatisasi Ring 0–3: Di dalam folder utama Google Drive Anda, buatlah 4 sub-folder bernama Ring 0, Ring 1, Ring 2, dan Ring 3. Setiap kali Anda menaruh file Google Docs/Word/Txt ke dalam sub-folder tersebut dan menekan tombol Sinkronkan dari Google Drive, sistem otomatis menempatkannya ke Ring yang tepat!
